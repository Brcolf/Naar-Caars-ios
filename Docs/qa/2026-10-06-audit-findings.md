# Audit findings and their status, 2026-10-06

Companion to [2026-10-06-functional-design-qa-pass.md](2026-10-06-functional-design-qa-pass.md). A read-only audit of the app produced 196 findings; two independent reviewers checked each one against the code (193 confirmed, 3 disputed in part, none refuted). This file lists every finding and where it stands after the fixes made the same day.

**145 fixed, 25 fixed in part, 26 open.** "Fixed in part" means the app-side defect is fixed and something outside the app code remains (a server change, a product decision, translations, or a part that needs a real device). Fixes were built and, where a simulator can show them, checked there; nothing here was run through the unit suite (see the report for why).

Severity is the auditor's. Ids are stable and are the ones used in commit notes and in the report.
