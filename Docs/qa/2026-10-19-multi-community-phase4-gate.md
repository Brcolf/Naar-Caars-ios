## PR Impact Summary

**Behaviour changes a reviewer must know about**

1. **Universal Links.** `https://naarscars.com/join#<code>` arrives through SwiftUI `onOpenURL` → `IncomingLinkHandler`, which saves the code in `PendingInviteStore` first (7 days, on the device) and then routes by launch state: signed in → My communities opens the Join sheet with the code (`DeepLinkParser.parse(url:)` → `DeepLink.joinCommunity(code:)` → `NavigationCoordinator.applyExternalDeepLink` → `NavigationIntent.joinCommunity`); signed out → the Welcome banner "You have an invite. Sign up or sign in to use it."; guest → the "Join the Community" prompt. The parser reads the code from the fragment only and refuses one in the query or path; logs show `joinCommunity(<code>)`. A link that arrives before the app is ready is replayed once. The deprecated `AppDelegate` URL path (`application(_:open:options:)`, `launchOptions[.url]`, and its `url.absoluteString` log) is removed. DEBUG builds accept `-debugIncomingURL <url>` for simulator checks.
2. **A new notification type, `membership_update`** (registry 33 → 34) on every layer: Swift enum, `NotificationTypeRegistry`, `notificationTypes.ts`, the SQL CHECK and `should_notify_user` (always on, `canBeDisabled == false`). Push taps route by `membership_event`: `approved` → My communities; `owner` with `community_id` → that community's Members (the screen refreshes the memberships first when opened from the push); bell rows route by the person's current role. It joins `membershipRefreshTypes`. **No server function produces it** until SQL File C opens (GATED); the count of such rows is 0.
3. **The announcement push contract is pinned** (`broadcast` with `community_id` and `town_hall_post_id` → Announcements, `broadcast_community.apns`); the server change that sends it (File B: one push per unmuted active member, no Town Hall side door) is GATED.
4. **Requests narrowed to one community shows how many open requests it hides** in the person's other communities (a local count over the rows the dashboard already holds; rows with no community and rows the list hides for time never count; `.all` shows nothing).
5. **Bell and announcement rows carry the community chip** when the person has more than one membership.
6. **Community time zone**: set from the device (`TimeZone.current`) at creation (`create_community(p_timezone)`), shown and editable by the owner in Settings (`update_community(p_timezone)`, sent only when changed), and used as the starting zone of the ride and favor forms for the community being posted to.
7. **Phase 2 and 3 gate follow-ups**: invite sheet buttons at AX 5 and the "1 time" plural; the owned-limit sheet's short title; one relabelled retry button on onboarding; Admin Panel management rows leading-aligned at AX 5; the Reports filter's tinted selected capsule (no literal `.white`) and edge fade; Profile stat labels localized; `ReportContentSheet` icons clear of their labels; the Admin Panel title follows a rename; the archive confirmation survives the move to onboarding or the waiting screen (`RootNotice`, cleared at sign-out); the A3 warning not showing after an archive is by design (pinned).

**Coordinator, realtime, send path.** `RefreshCoordinator.swift` is unchanged and **no coordinator call is added**. Realtime, `MessageSendManager`, reactions, SwiftData models and mappers, `BadgeCountManager` and `get_badge_counts` are unchanged (`membership_update` rows are counted by the bell's existing per-notification arm).

**High-blast-radius seams touched, and what breaks if a consumer is missed**

| Seam | Change | If a consumer were missed |
|---|---|---|
| `NotificationType` / `NotificationTypeRegistry` / `notificationTypes.ts` / SQL CHECK | `membership_update` on all four layers; `validate-notification-types.sh` now also reads the SQL CHECK | A layer without it: the edge function drops the push, the CHECK rejects the row (the producer's RPC fails), or an old client decodes it as `.other` and opens the dashboard; `validate-notification-types.sh` exits non-zero. |
| `DeepLinkParser` | `parse(url:)` for the join link (fragment only); `membership_update` payloads → `.myCommunities` / `.communityMembers(communityId:)` by `membership_event`; `DeepLink.logDescription` hides the code | A path that reads the query or logs the URL leaks a bearer secret; a missing `membership_event` arm sends an owner push to the dashboard. |
| `NavigationIntent` | `.communityMembers(UUID)`, `.joinCommunity` (no code: the store holds it), both in the Profile-tab group | A `switch` without the cases stops compiling; a tab mapping without them opens the wrong tab. |
| `NavigationCoordinator` | `applyExternalDeepLink(_:)`, `guestPromptReason(for:)`, `NotificationIntent.openCommunityMembers(communityId:)` | A link while not ready is lost or applied twice; a guest gets no prompt; the deferred-intent match drops the new intents. |
| `NotificationNavigationRouter` | Injected `isAdminOf`; `membership_update` rows → Members for an admin of the row's community, else My communities | A row routes to a screen the person cannot open, or never to Members after an ownership change. |
| `AppDelegate` | URL handling removed; `.communityMembers` passes through; `.joinCommunity` is never produced from a push | A reintroduced delegate URL path would log the URL and bypass the store; a push intent missing from the group is dropped. |
| `PushNotificationService` (`PushRefreshPlan`) | `.membershipUpdate` in `membershipRefreshTypes` | A push that changes a role would leave the cached memberships stale until the next foreground. |
| `Constants` | `URLs.universalLinkHost`, `joinPath`, `joinLink(code:)`; `Community.shareInviteLinks = false` | A host or path that differs from the entitlement and AASA file makes links open Safari; flipping `shareInviteLinks` before the AASA and landing page are live sends links to a missing page. |
| Supabase RPC call sites | `create_community(p_name, p_description, p_join_policy, p_timezone)` (`p_timezone` omitted when nil); `update_community(… p_timezone)` only on a change | Against a server without File A, Create fails ("Could not find the function"); File A is live (step 1). |
