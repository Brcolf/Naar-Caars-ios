# Community Release 2 (discovery) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let anyone find a listed community by name, town, ZIP code or "Use my location"; let owners start a listed community with a service area and a soft nearby check, switch listed and join policy later, and merge two communities by mutual agreement; and give Test Community example requests that can be read and questioned but never claimed.

**Architecture:** Explore's search tab gets `.searchable` driven by one `ExploreSearchViewModel` that runs a name search and, when the text is a town or ZIP code, a MapKit geocode plus a place search, through the Release 2 RPCs of the companion SQL plan; the same search panel replaces the public-list join options on Get started and the waiting screen. Service areas are one reusable draft model and picker used by Start a community (steps 2-4) and the owner's new access screen; merging is one screen under Manage backed by a narrow `CommunityMergeServiceProtocol`, and `CommunityContext` swaps a merged-away community for its survivor. Example requests add one additive field to the Ride and Favor SwiftData trio; no refresh domain, notification type or messaging file changes.

**Tech Stack:** Swift 6.3 toolchain in Swift 5 mode, SwiftUI (`.searchable` on the `Tab(role: .search)`, `Map` with `MapCircle`), MapKit `MKGeocodingRequest` / `MKReverseGeocodingRequest` (iOS 26), Core Location (one "while using" fix), SwiftData, XCTest, Xcode 26.6 / iOS 26.5 SDK, Supabase RPCs.

**Spec:** `Docs/superpowers/specs/2026-10-21-community-discovery-and-trust-design.md` (4.1, 4.2, 4.9 S3/S4/S7/S8, 4.10 "Release 2", 4.11, 4.12; where it differs from the mockups `build/design/mockups/navigation-mockups.html`, the spec wins). Server: `Docs/superpowers/plans/2026-10-21-community-release2-discovery-sql.md`. Builds on `Docs/superpowers/plans/2026-10-21-community-release1-navigation.md` (names in its "Interfaces later releases rely on"). Read all three and CLAUDE.md before a task.
